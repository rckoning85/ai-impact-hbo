# AI en het hbo-werkveld

Een website die per sector laat zien wat AI betekent voor het Nederlandse werkveld waarvoor
Hogeschool Leiden opleidt. Eén zin per sector, gebaseerd op betrouwbaar onderzoek, wekelijks bijgewerkt.

**Bekijk de site:** https://rckoning85.github.io/ai-impact-hbo/

- Hoe bronnen worden gekozen en gewogen: [METHODE.md](METHODE.md)
- Een bron voorstellen: via de knop *Bron voorstellen* op de pagina *Alle doorzochte bronnen*, of
  [direct hier](https://github.com/rckoning85/ai-impact-hbo/issues/new?template=bron-voorstellen.yml).

Gemaakt door Robert Koning, AI-Team Hogeschool Leiden.
